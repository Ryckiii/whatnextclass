# 课表与 DDL

一个极简静态课表网站。支持手动选择星期、滚动浏览当天课程、自动定位当前时段、DDL 本地保存及到期清理。再也不用跑去看课表啦啦啦啦，再也不用担心错过ddl啦啦啦

**无依赖、无构建步骤、无后端。入口文件为 `index.html`。**

## 文件结构

```text
offline-timetable/
├── index.html    # 完整应用：样式、脚本、SVG、礼花均内嵌
├── README.md     # 使用与部署说明
├── .gitignore    # 排除常见系统和开发临时文件
└── .nojekyll     # GitHub Pages 按静态文件提供页面
```

部署时，把这个文件夹内的内容放到 Git 仓库根目录。不要只把整个 `offline-timetable` 文件夹放进去，否则访问路径会多一层 `/offline-timetable/`。

## 本地使用

直接用现代浏览器打开 `index.html`，不需要联网。

如需通过本地 HTTP 服务检查，且已安装 Python，可在此目录执行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。这只是可选的本地检查方式，部署不需要 Python。

## GitHub Pages 部署（推荐简单方式）

无需 Actions 工作流或 npm 构建。

1. 新建 GitHub 仓库，或打开你希望使用的现有仓库。
2. 将本目录中的文件提交到仓库根目录，确保根目录能直接看到 `index.html`。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
5. 选择包含网站文件的分支（通常为 `main`），目录选择 **/(root)**，点击 **Save**。
6. 等待部署完成，使用 Pages 页面显示的网站地址访问。

普通项目仓库的网站地址通常为：

```text
https://<用户名>.github.io/<仓库名>/
```

此应用没有以 `/` 开头的资源路径，也没有路由重写要求，可以直接运行在仓库子路径下。

> GitHub Pages 是否可用于私有仓库取决于账户方案与组织设置。如果找不到 Pages 设置，请先检查仓库权限和 Pages 可用性。

### 已克隆仓库的命令行提交方式

先将本目录内的文件复制到已克隆仓库的根目录；若已有同名文件，请先检查内容，避免覆盖原网站或项目配置。然后在仓库根目录执行：

```bash
git add index.html README.md .gitignore .nojekyll
git commit -m "Add timetable and local deadline app"
git push
```

无需把 `node_modules`、自动化测试截图或工具脚本放进仓库，本包已排除这些文件。

## 其它静态托管平台

只要平台能够托管静态 HTML，即可使用此文件夹。常见配置为：

- 项目类型／框架：静态网站或 None / Other。
- 构建命令：不需要，留空。
- 发布目录：存放 `index.html` 的目录；若界面允许，可填 `.` 表示仓库根目录。
- 入口：`index.html`。
- 环境变量：无。
- 后端服务／数据库：无。

Git 仓库本身只存储代码；要通过网址使用，还需要开启 Pages 或连接静态托管服务。

## 使用说明

- 先手动选择周一至周五，确认后进入课表，不会自动按实际日历星期选择。
- 课表页以 Mon / Tue / Wed / Thu / Fri 标注选定星期。
- 中央列表支持鼠标滚轮、触屏滑动、方向键及 Home / End；只显示课程名称，包含九节课与两节晚自习。
- 当前课程以大号文字突出显示。休息期间显示当前休息状态，不把其它休息时段混入课程列表。
- 手动浏览后，可点击星期按钮旁的定位图标回到当前时段。
- 左上角加号添加 DDL，日期格式为 `yyyy.mm.dd`。列表最多显示三行，可继续滚动；悬停、键盘聚焦或触屏可使用删除按钮。
- 21:00 后显示完成提示；关闭后返回选择页，当天不重复提示。
- 本地午夜清空所选星期并清理过期 DDL。浏览器暂停后台标签页时，会在恢复可见或焦点时重新核对日期。

## 数据与离线使用的重要说明

- DDL 与已关闭完成提示的日期只保存在当前浏览器的 `localStorage`，应用不会将它们上传到服务器或 Git 仓库。
- 同一浏览器、同一站点来源下更新网站文件，通常会保留已有 DDL。本包保持了旧版本的存储键名与数据格式。
- 从本地文件改为网站地址、切换域名／协议／端口、换浏览器或清除站点数据时，原有 DDL 不会自动迁移。
- `localStorage` 按“协议 + 域名 + 端口”隔离，不按仓库路径隔离。在同一 `用户名.github.io` 域名下部署多个本应用副本，会共享同一组存储键及 DDL 数据。
- 隐私模式或浏览器禁用存储时，数据可能无法长期保存；保存失败时页面会提示。
- 下载后的 `index.html` 可以完全离线打开。部署到网站后，首次访问需要联网；本包未添加 Service Worker，因此不保证断网时重新导航到网站地址能打开。已加载页面的功能与 DDL 操作不依赖网络。
- 清除浏览器数据、变更网站来源前，请自行记录重要 DDL；本版未增加云同步或导入导出功能。
